## Helpers

- `theme/orbit-upgrade-snippets.css` gives ready CSS snippets for low opacity background textures, role badges, title bar logo sizing, and create/join choice cards.
- `docs/asset-map.json` maps every requested feature to the exact file.

All assets in this pack are custom Orbit-themed assets.

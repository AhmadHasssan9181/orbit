# Orbit SVG Wallpaper Pack

20 original WhatsApp-style doodle wallpapers for Orbit.

These are SVG vector backgrounds with subtle chat, orbit, media, star, pin, mic, gift, image, phone, and community doodles.

## Types included

- 4 dark backgrounds
- 4 light backgrounds
- 4 grey backgrounds
- 4 AMOLED backgrounds
- 4 mixed accent backgrounds

## Recommended usage

Use these as low-noise chat backgrounds or empty-space backgrounds.

For chat screens:
- dark wallpapers: 100 percent opacity
- light wallpapers: 100 percent opacity
- AMOLED wallpapers: 100 percent opacity
- mixed wallpapers: 85 to 100 percent opacity

For dialogs or panels:
- place behind a translucent card
- keep overlay opacity around 0.04 to 0.08

All artwork is original and not copied from WhatsApp.
